## Disclaimer
Please take time to read the following!

### General overview

These scripts are written for, and developed on, Arch-based SteamOS installations (Valve's Steam Deck OS and Arch-based derivatives such as Bazzite). By using this repository, you accept all associated risk. If you are not comfortable using unofficial software and scripts, I do not suggest continuing.

### Backup your data!

Usage of these scripts is at your own risk! If you are at all concerned about the safety of your installation, **please** have a recent system backup ready before running anything here. Bazzite/SteamOS 3.x images are easy to re-flash from Valve/the image maintainer's recovery tooling if something goes wrong, but that won't preserve your `/home` data - back that up separately if you're concerned about it.

### Installing and Uninstalling software

Please pay careful attention while installing software, or using any scripts that require software installation (Flatpaks, AppImages, etc). I do my best to ensure no script is going to remove or overwrite a package Valve/your OS maintainer ships, but please be advised. If a script requires removing software, please read the output thoroughly before proceeding.

### Conclusion

If you disregard any of these points, I will **not** be responsible for damage done to your installation. Please heed these warnings! Mistakes happen with updates and the like. If you experience any issues, please submit an [issues](https://github.com/mdeguzis/SteamOS-Tools/issues) ticket.
